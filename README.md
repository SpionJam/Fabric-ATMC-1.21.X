# Minecraft Mod Projekt

## Überblick:

Dieses Projekt ist eine Minecraft Mod, die im Rahmen eines 6-wöchigen Schulprojekts im Team entwickelt wurde.
Ich habe dabei die Rolle des Teamleiters übernommen und die Entwicklung koordiniert.

Die Mod ist nicht vollständig fertiggestellt, da sie im vorgegebenen Zeitrahmen nicht vollständig umgesetzt werden konnte.

## Ziel des Projekts:

Ziel des Projekts war die Entwicklung einer eigenen Minecraft Mod, die neue Inhalte und Gameplay-Features in das Spiel integriert.

Die Mod sollte unter anderem folgende Inhalte hinzufügen:

- Neue Items und Ressourcen
- Neue Blöcke
- Eigene Advancements (Erfolge)
- Neue Mobs (Entitäten)
- Waffen, Rüstungen und Werkzeuge
- Neue Strukturen und Gebäude

## Verwendete Technologien:

- **Programmiersprachen:** Java, JSON
- **Minecraft Modding API:** Fabric
- **Build-System:** Gradle
- **Entwicklungsumgebung:** IntelliJ IDEA
- **Versionskontrolle:** Git
- **Bildbearbeitung:** Paint.NET
- **Modellierung:** Blockbench
- **Unterstützende Tools & Ressourcen:** Verschiedene Webseiten zur einfacheren Erstellung von Rezepten und weiteren Mod-Inhalten
